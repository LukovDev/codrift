# Codrift

3D-визуализатор структуры кода: C (а также C++, Java, C#, JavaScript/TypeScript и Python — см. «Языки»). Работает полностью в браузере: без бэкенда, без сборки, без записи файлов на диск. Подходит для GitHub Pages.

- **Виды:** граф `#include`, граф вызовов (функции или файлы), API заголовков (функции, макросы, типы, переменные → где объявлены и где реализованы), дерево директорий, статистика.
- **Источники:** публичный GitHub-репозиторий (опционально токен — хранится только в памяти вкладки), локальная папка (File System Access API или `webkitdirectory`), `.zip`, отдельные файлы.
- **Поиск и список узлов:** пустое поле поиска показывает все узлы текущего вида списком (на «Статистике» — все файлы и функции). Сортировка: по алфавиту, по длине имени, по числу строк, по числу связей; повторное нажатие меняет направление. С запросом — те же сортировки среди совпадений, точное совпадение имени всегда первое. Длинные списки подгружаются по мере прокрутки.
- **Фильтр на лету** (вкладка «Вид»): строка вида `src/cgdf !opengl` (слова и glob-маски — путь подходит, `!маска` — исключить) и скрытие отдельных модулей. Граф перестраивается сразу, без повторного разбора; позиции узлов сохраняются.
- **Обновление проекта:** кнопка ⟳ или клавиша `R` перечитывает источник. Для папки, открытой через File System Access API, включено наблюдение: изменённые, новые и удалённые файлы подхватываются автоматически (проверка раз в 2,5 с, список файлов — раз в ~10 с).
- **Фильтры:** glob-списки «игнорировать» и «искать только в», расширения (указали хоть одно расширение языка — берутся все его, например `.cpp` подтягивает `.hpp`), каталоги include. По умолчанию игнорируются типичные каталоги сторонних библиотек (`vendor`, `third_party`, `external`, `libs`, `glad`, `cglm`, `SDL*`, `stb_*` …).
- **Документация:** описания берутся из комментариев над объявлениями (или в конце строки) и показываются в панели деталей. Экспорт в Markdown (весь проект / только заголовки / один файл).
- **Стили сцены — пресеты** «Простой» (по умолчанию), «Атомы», «Космос», «Неон», «Чертёж». Любой параметр пресета меняется вручную: палитра, форма узлов (сфера / кристалл / каркас), материал (матовый / мягкий / светящийся), ободок-контур (при любом материале), свечение (bloom), орбиты и электроны, импульсы (скорость и частота настраиваются), туман, тепловое дрожание, вращение, фон (градиент / звёзды / процедурная туманность с новым «зерном» по кнопке / сетка).
- **Производительность:** невидимые узлы и связи отбрасываются до отрисовки (frustum culling); кадры рисуются только при движении или анимации; без касаний фоновая анимация идёт на 30 к/с и засыпает после бездействия (по умолчанию 45 с). Разрешение «Авто» само понижается при просадке FPS; «Максимум» — родное разрешение экрана (на телефонах ×3). Кнопка «Максимальная графика» (вкладка «Экран») одним нажатием ставит родное разрешение, MSAA, самые гладкие узлы и снимает ограничение кадров (на iPhone Pro — до 120 Гц). Есть ограничение FPS, сглаживание MSAA, счётчик FPS; свечение считается в полном разрешении (на телефонах — в 0.75). Узлы и связи рисуются несколькими вызовами отрисовки независимо от размера графа.
- **Экспорт PNG:** масштаб 1×–4× (до 8192 px), по выбору с подписями, легендой и заголовком.
- **Стиль «Космос»**: узлы как светящиеся огранённые ядра атомов с электронными оболочками, связи — светящиеся «химические» связи с бегущими импульсами, звёздное поле и туманности, свечение (bloom), тепловое дрожание, медленное вращение. Функции одного файла (и файлы одной папки) стягиваются в «молекулы».
- **Косвенные вызовы:** вызовы через указатели на функции (`obj->field(...)`) связываются со всеми функциями, которые этому полю присваиваются: `x->field = fn`, `{ .field = fn }` или позиционный инициализатор `{ fn1, fn2 }` по порядку полей структуры. Кандидаты отбираются по числу аргументов. В CGDF так видно, что `MainLoop` вызывает `start/update/render…` всех сцен.
- **Камера:** плавное орбитальное управление: по умолчанию свободное вращение (без «верха» и «низа»), по галочке во вкладке «Экран» — классическое (горизонт ровный, наклон до ±89°), перелёт к узлу с центрированием, сдвиг изображения под панель деталей, изометрическая проекция с плавным переходом (кнопка на панели справа или вкладка «Экран»).
- **Выделение** общее для всех видов: функция в «Вызовах» ↔ её файл в `#include`/«Директориях», выбор строки в «Статистике» открывает узел в графе. Снятие выделения (клик по фону, `Esc`, ✕) оставляет камеру на месте и немного отдаляет её.
- **Построение:** граф появляется волной от самого связанного узла по связям — каждый узел вырастает из соседа и выезжает на своё место. При фильтре и переключении модулей стоящие узлы остаются на местах, новые вырастают из соседей, подписи и панель деталей не пересоздаются.
- **Пауза** (кнопка ⏸) замораживает раскладку и останавливает рождение импульсов: уже летящие долетают до конца связи, после «продолжить» новые появляются снова.
- **Подписи** (до 1000) по умолчанию есть и у внешних узлов и макросов; при приближении подписываются крупные на экране узлы и их соседи.
- **Смена и обновление проекта:** после загрузки другого проекта или перечитывания текущего камера показывает граф целиком.
- **Интерфейс:** английский по умолчанию (кнопка RU/EN переключает и запоминает выбор), плавные анимации панелей, вкладок и списков.
- **Настройки:** раскладка (силы / дерево / радиально), цвет (тип / модуль / метрика), размер узлов (по умолчанию — сумма размеров по строкам и по числу связей), физика (отталкивание, длина связей, притяжение, сцепление в молекулы, трение), стиль, подписи по типам узлов, плавность камеры.

## Запуск

Выложите папку на GitHub Pages или запустите локально любой статический сервер в этой папке, например `python -m http.server 8000`, и откройте `http://localhost:8000/`. Открытие `index.html` через `file://` тоже работает (библиотеки берутся с CDN), но браузер не даёт такой странице менять свой адрес — состояние тогда не попадает в адресную строку; ссылку на вид можно получить кнопкой «Скопировать ссылку».
Ссылки вида `index.html?repo=owner/repo&ref=branch&view=calls` сразу загружают репозиторий.

### Телефон и веб-приложение

Сайт можно добавить на экран «Домой» (Safari: «Поделиться → На экран „Домой“», Chrome: «Установить приложение») — он откроется на весь экран со своим значком (`manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`). Сверху оставлен отступ под строку состояния и Dynamic Island, снизу — под полосу жестов. Страница не масштабируется щипком и двойным тапом, поля ввода не увеличивают её при фокусе — масштабируется только сам граф. Шторку деталей можно тянуть: вверх — развернуть, вниз — свернуть или закрыть.

### Состояние в ссылке

Адресная строка всегда содержит текущее состояние, поэтому ссылку можно просто скопировать. Кнопка «Скопировать ссылку на вид» добавляет ещё и камеру. В ссылку попадает только то, что отличается от значений по умолчанию.

| Параметр | Что задаёт | Пример |
|---|---|---|
| `repo`, `ref` | репозиторий GitHub и ветку | `repo=LukovDev/CGDF&ref=master` |
| `snap` | снимок `.drift` по ссылке (вместо `repo`) | `snap=cgdf.drift` |
| `view` | вид: `includes`, `calls`, `api`, `dirs`, `stats` | `view=calls` |
| `vo` | опции видов `вид.ключ:значение` | `vo=calls.layout:td,calls.showExt:1` |
| `style` | пресет: `simple`, `atoms`, `cosmos`, `neon`, `blueprint` | `style=neon` |
| `vs` | отличия от пресета `ключ:значение` | `vs=bloom:0,glow:1.2,sky:stars` |
| `lk` | подписи по типам узлов | `lk=ext:1,macro:0` |
| `lf`, `hm` | фильтр на лету и скрытые модули | `lf=src/cgdf !opengl&hm=game/src` |
| `ign`, `only`, `exts`, `roots`, `maxkb`, `maxf` | фильтры файлов (списки через `;`) | `only=src/cgdf` |
| `sel`, `focus` | выделенный узел и показ только его окрестности (глубина) | `sel=fn:MainLoop@src/cgdf/graphics/opengl/window.c&focus=1` |
| `cam` | камера: кватернион поворота и приближение (старый формат из трёх чисел тоже читается) | `cam=0.1,0.3,0,0.95,0.8` |
| `lang`, `theme` | язык и тема | `lang=en&theme=dark` |
| `embed` | режим встраивания в iframe (без панели источника) | `embed=1` |

### Снимки и экспорт

- **Снимок проекта `.drift`** (вкладка «Экспорт») — сжатый gzip JSON: результат разбора, раскладка текущего вида и настройки, по желанию с исходным кодом. Можно сохранить и без сжатия (`.drift.json`). Открывается во вкладке «Снимок» панели «Источник» (из файла или по ссылке), перетаскиванием на страницу или ссылкой `?snap=путь/к/файлу.drift`. Снимки прежнего формата `.ccv` тоже открываются. Повторного разбора и запросов к GitHub не нужно; раскладка восстанавливается точно.
- **Граф текущего вида:** GLB (3D-модель для Blender, узлы — именованные объекты), GEXF (Gephi, с позициями и цветами), GraphML (yEd, Cytoscape), DOT (Graphviz), JSON.

Зависимости (CDN jsDelivr, версии зафиксированы): `three@0.174.0` (вместе с `UnrealBloomPass`), `3d-force-graph@1.77.0`; `fflate@0.8.2` подгружается только для zip.

## Управление

| | Мышь | Тач |
|---|---|---|
| Вращение | левая кнопка | один палец |
| Сдвиг | правая/средняя кнопка или Shift + левая | два пальца |
| Масштаб | колесо | щипок |
| Выбор узла | клик | тап |
| Список узлов | клик в пустое поле поиска | тап в пустое поле поиска |

`/` — фокус в поиск, `Esc` — закрыть настройки / снять выделение, `R` — обновить проект.

Панель настроек закрывается тапом или кликом в любом месте вне неё, в том числе по графу (такой тап только закрывает панель и не выбирает узел). Вращение и масштаб графа панель не закрывают — можно настраивать и сразу смотреть результат.

## Парсер

`parser.js` — лёгкий эвристический разбор без препроцессора: корректно вырезает комментарии и литералы, разбирает `#include`/`#define`, условную компиляцию (`#if 0` и `#else`-ветки не участвуют в разборе тел), объявления и определения функций (включая C23-атрибуты `[[...]]`), `struct/union/enum/typedef`, глобальные переменные и вызовы внутри тел функций. Вызовы через макросы разворачиваются до реальных функций.

Ограничения: код, генерируемый макросами (например, функции, объявленные через `DEFINE_X(name)`), не распознаётся. Вызов через указатель на функцию, который хранится в локальной переменной или параметре, не разрешается. Через поля структур — разрешается, см. «Косвенные вызовы».

## Языки

Разбор подключается плагинами (`langs.js`, реестр `CodriftLangs`); язык файла определяется по расширению. Если файлов выбранных расширений нет, сайт сам определяет основные языки проекта. Галочки языков в фильтрах источника добавляют или убирают их расширения.

| Язык | Расширения | Связи «импорта» |
|---|---|---|
| C | `.c .h` | `#include` |
| C++ | `.cpp .cc .cxx .c++ .hpp .hh .hxx .h++ .ipp .tpp .inl .ixx .cppm` (и `.h`, если в проекте есть C++) | `#include` |
| Java | `.java` | `import` → файл класса (и `pkg.*`) |
| C# | `.cs` | `using` → файлы пространства имён |
| JS / TS | `.js .jsx .mjs .cjs .ts .tsx .mts .cts` | `import`, `require`, `export … from` (относительные пути) |
| Python | `.py .pyi .pyw` | `import`, `from … import` (абсолютные и относительные) |

Функции получают имя `Класс.метод`; вызовы `this.f()`/`self.f()` связываются с методом своего класса, конструкторы — с `new Foo()`/`Foo()`. Вызов параметра-колбэка (`fn()`, `cb()`) не путается с одноимённой функцией проекта, вызовы разрешаются только внутри своего языка (C и C++ видят друг друга). Макросы экспорта (`class SPDLOG_API logger`) пропускаются, шаблоны и обобщения (`template<class T>`, `foo<T>(x)`) понимаются.

Новый язык — объект `{ id, name, exts, parse(path, text), isHeader?, hasHeaders, oop, resolveImport?(file, imp, ctx) }`, зарегистрированный через `CodriftLangs.register(...)`. Для C-подобного синтаксиса есть конструктор `makeBraceLang(cfg)`. `parse` возвращает тот же формат, что и `CParser.parseFile`: `includes`, `funcs` (с `name`, `container`, `sig`, `calls`, `ids`, `memberCalls`, `doc`), `types`, `vars`, `macros`, `decls`.

## Лимиты GitHub

Без токена GitHub API даёт 60 запросов в час на IP. На одну загрузку уходит один запрос (дерево файлов), а содержимое читается через `raw.githubusercontent.com`. С токеном всё идёт через API.
